# Design (`design/`)

Concentrated UI and UX skills for web and desktop application interfaces.

| Skill | Scope & Trigger |
| :--- | :--- |
| [**`ui-design`**](./ui-design/SKILL.md) | Visual hierarchy, layout density, cognitive load subtraction, silent normal states (no badge spam), functional color restraint, and typography/token discipline. |
| [**`ux-interaction`**](./ux-interaction/SKILL.md) | Direct manipulation (instant local search/filter, inline editing over modals, progressive disclosure), inline state feedback (`Show, Don't Tell`), complete state coverage (`loading`, `empty`, `error`, `disabled`), layout-stable hover/focus states, and scroll/keyboard ergonomics. |
