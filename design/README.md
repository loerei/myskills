# Design

Interface design, styling, typography, brand guidelines, UI taste, visual generation, and UX optimization.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[brandkit](./brandkit/SKILL.md)** — Brand design system generator for color palettes, typography pairs, layout grids, and visual guidelines.
- **[design-taste-frontend](./design-taste-frontend/SKILL.md)** — Anti-slop frontend skill for landing pages, portfolios, and redesigns. Infers design direction, enforces real design systems, and ships non-templated UIs.
- **[design-taste-frontend-v1](./design-taste-frontend-v1/SKILL.md)** — Original v1 taste skill preserved for projects requiring exact backward compatibility.
- **[gpt-tasteskill](./gpt-tasteskill/SKILL.md)** — GPT-tailored UI taste rules for modern typography, sleek dark modes, and dynamic micro-interactions.
- **[high-end-visual-design](./high-end-visual-design/SKILL.md)** — High-end agency design system for luxury aesthetics, custom typography, calibrated spacing, and premium shadows.
- **[image-to-code](./image-to-code/SKILL.md)** — Convert design screenshots, mockups, or UI images directly into clean, responsive HTML/CSS or React components.
- **[imagegen-frontend-mobile](./imagegen-frontend-mobile/SKILL.md)** — Generate visual assets, UI mockups, and illustrative components optimized for mobile app layouts.
- **[imagegen-frontend-web](./imagegen-frontend-web/SKILL.md)** — Generate visual assets, Hero images, background graphics, and UI components for web applications.
- **[industrial-brutalist-ui](./industrial-brutalist-ui/SKILL.md)** — Raw mechanical interfaces fusing Swiss typographic print with military terminal aesthetics for data-heavy dashboards and portfolios.
- **[minimalist-skill](./minimalist-skill/SKILL.md)** — Clean, minimalist visual design system focusing on whitespace, precise typography, and subtle micro-interactions.
- **[redesign-existing-projects](./redesign-existing-projects/SKILL.md)** — Upgrade existing websites and web apps to premium quality without breaking existing functionality.
- **[stitch-design-taste](./stitch-design-taste/SKILL.md)** — Semantic design system skill for Google Stitch enforcing strict typography, calibrated color, and perpetual micro-motion. Subdoc: [DESIGN.md](./stitch-design-taste/DESIGN.md)
- **[taste-skill](./taste-skill/SKILL.md)** — Core taste principles for UI layout balance, visual hierarchy, and polished component styling.
- **[ux-friction-killer](./ux-friction-killer/SKILL.md)** — Audit and eliminate UX friction, awkward interaction patterns, and slow user flows.
