# Personal

Personal notes, Obsidian vault management, creative writing, draft shaping, and narrative structuring.

## User-invoked

Reachable only when you type them (Claude Code: `disable-model-invocation: true`; Codex: `policy.allow_implicit_invocation: false` in `agents/openai.yaml`).

- **[edit-article](./edit-article/SKILL.md)** — Edit and improve articles by restructuring sections, improving clarity, and tightening prose.
- **[ubiquitous-language](./ubiquitous-language/SKILL.md)** — Extract a DDD-style ubiquitous language glossary from the current conversation and save to `UBIQUITOUS_LANGUAGE.md`.
- **[writing-beats](./writing-beats/SKILL.md)** — Writing (exploit phase): Assemble raw material into an interactive journey of beats, grounding concepts step-by-step.
- **[writing-fragments](./writing-fragments/SKILL.md)** — Writing (explore phase): Mine raw fragments and ideas freely without imposing premature structure.
- **[writing-shape](./writing-shape/SKILL.md)** — Writing (exploit phase): Shape raw material into a polished article, paragraph by paragraph.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[obsidian-vault](./obsidian-vault/SKILL.md)** — Search, create, and manage notes, index notes, and wikilinks inside the Obsidian vault.
